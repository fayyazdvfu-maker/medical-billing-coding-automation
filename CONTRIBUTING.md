# Contributing

Open an issue describing the problem and a synthetic reproducer. Keep changes
focused and run `python -m unittest discover -s tests -v` before submitting a PR.
For rule changes, include the authoritative source, relevant policy version,
effective dates, payer applicability and tests covering matching/nonmatching cases.
Do not contribute patient information, secrets, or coding datasets you cannot
redistribute. Document proposed features as planned until they are implemented.
